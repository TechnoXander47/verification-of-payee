# Verification of Payee

This repository contains one-page, A4 PDF documents introducing and explaining TechnoXander’s [Verification of Payee (VoP)](https://technoxander.com/verification-of-payee/) solution for SEPA payments.

## About the solution

Verification of Payee is a real-time name-checking service for SEPA credit transfers that compares payee name details with the account holder information for a provided IBAN before payment authorisation. TechnoXander provides an EPC-approved Routing and Verification Mechanism (RVM) with requester and responder capabilities, returning Full Match, Close Match or No Match results to support informed payment decisions.
